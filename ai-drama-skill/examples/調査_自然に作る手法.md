# 調査：AIドラマを自然に作っている人たちの手法（2026-10-06）

v1/v2が不自然だった理由を自分の感覚でなく、公開情報で確認した。結論は「**音声を分けて後から口を合わせる方式そのものが間違い**。Seedanceにセリフを渡して映像・声・口・カット割りを同時に生成し、1生成で3ショット15〜20秒を作る」。

## 1. 音声は分けない（ネイティブ音声）
- セリフは `{ }` で書き、言語を前置き（`女性が日本語で言う：{…}`）。モデルが声・口の動き・カットのタイミングを同時生成する。括弧は 音楽`( )`／効果音`< >`／セリフ`{ }`／字幕`【 】`（[morphic](https://morphic.com/jp/resources/how-to/seedance-2-guide)、[CreativeEdge 2.5記法](https://note.com/creative_edge/n/nc9f095edf474)、[OSideMedia Seedance2.5 skill](https://github.com/OSideMedia/higgsfield-ai-prompt-skill/blob/main/skills/higgsfield-seedance-2-5/SKILL.md)）
- 1人1ショットあたり1〜2文。15秒で25〜30語が上限目安。長いと口がずれる（[fal.ai](https://fal.ai/learn/tools/seedance-2-0-prompting-guide)、[videoai.me](https://videoai.me/blog/seedance-2-0-dialogue-prompts)）
- 話者は秒ブロックで分ける（0-3s Aが話す／3-6s Bが返す）。「他の人物の口は閉じたまま」を書く（[fal.ai 2.5](https://fal.ai/learn/devs/seedance-2-5-prompting-guide)、[いにしえ 究極ガイド](https://note.com/old_pgmrs_will/n/n442174cf60ed)）
- 声は参照画像から推定される。「20代の東京の女性の声、自然な日本語」のように声を明示しないと勝手にキャスティングされる（[mindstudio review](https://www.mindstudio.ai/blog/seedance-2-5-review-guide)）
- 日本語のリップシンクは実用レベルという報告が複数（[weel](https://weel.co.jp/media/tech/seedance-summary/)、[いにしえ]）
- 「No music」「NO BGM」はディエジェティック音のリストの後に書く。`( )` の中に否定を書かない

## 2. 1生成＝3ショット15〜20秒。1生成1機能
- 単位の目安：フック12〜16秒／対峙15〜20秒／反転12〜18秒／引き10〜15秒。「各タスクは1つの叙事機能のみ」（[seedance-ai.hk](https://seedance-ai.hk/ja/blog/seedance-2-5-short-drama/)）
- 骨格：Shot1 広め/中景で空間を立てる → Shot2 中景で対峙・動作 → Shot3 顔アップで転換。**同じ構図を2回続けない**（[鷹の目週末プログラマー](https://note.com/takaweekendprog/n/nfe59410129c3)）
- 会話は「ツーショットで始めて、話している方の寄りにカット」。会話中はカメラをロックするか、ゆっくり寄るだけ。カメラが動くと口がずれる（[fal.ai]）
- 各ステージは「初期状態→主要な出来事1つ→終了状態」を書く。感情語（緊張感）でなく観察できる状態（視線・眉・呼吸）を書く（[CreativeEdge]）
- 30秒生成は会話シーンで有用、リテイクが減る。壊れた区間は切って使う（[mindstudio]）

## 3. 人物の固定
- 人物1人につき参照1〜2枚。「@Image 1 は〇〇の顔・髪・服だけを定義する。背景と構図は使わない」と**役割＋除外**を1文で書く。1プロンプトに3人以上は入れない（[seedance-ai.hk]、[CreativeEdge]、[domoai](https://www.domoai.app/blog/seedance-2-5-character-consistency)）
- 場所も参照画像を分けて「画像内の人物は使わない」。参照を増やすほど不安定（[domoai]）
- 服装キーワードを毎回繰り返す。「2人を入れ替えない／人数は2人のまま／衣装を変えない」を[一貫性の維持]に列挙
- 年齢を書かない（twin effect対策。役割・体格・服・動作で書く）（[OSideMedia]）

## 4. 自然に見せる演出
- カメラ目線にしない。セリフは相手に向かって言う。「説明」も対話で（本件でユーザー指示）
- セリフ1本に身体動作を1つ対にする（身を乗り出す、グラスを握る）。感情は副詞でなく身体で（[prompt-architects](https://prompt-architects.com/blog/101-veo-dialogue-prompts)）
- やり過ぎ防止句：「自然な口の動き、口を大げさに開けない、話しながら首を振らない」（[fal.ai]）
- 事件は因果の順で書く（接触→動き→知覚）。「水が顔に当たる→のけぞる→周りが息を呑む」

## 5. 制作プロセス
- 全編を一度に作らない。成立に欠かせない場面を先に1本試作し、つながりを仮編集で確認（[ナイトてんしょん](https://nightension.com/shortdramalab/blog77/)）
- プロの作例はトレーラー1本に「約100生成、没は数百」（[Higgsfield Zephyr](https://higgsfield.ai/blog/guide-youtube-seedance2.0)）。1発で決まる前提を捨てる
- 字幕は生成音声をWhisperで文字起こしして位置を取る（セリフを分けないので、こちらで時刻を知る手段）

## v1/v2との差分
| | v1/v2（自作） | 公開されている作法 |
|---|---|---|
| 音声 | TTSを別撮りして口を合わせる | セリフをプロンプトに書き、声・口・間を同時生成 |
| 単位 | 1枚絵＋1セリフを22本つなぐ | 1生成3ショット15〜20秒を3本 |
| 視線 | 説明役がカメラに向かって話す | 相手に向かって話す。カメラは第三者 |
| 人物 | 絵ごとに編集生成 | 参照1〜2枚＋役割/除外文で固定 |
| 演技 | 感情タグ | 身体動作と状態変化で書く |
