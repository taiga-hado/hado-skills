# 共通の禁止リスト

## 見た目
- 紫〜青のグラデーション背景
- 同じ形のカードを横に3つ並べて情報量を稼ぐ
- 大きな数字＋小さなラベル＋グラデーションのHero（テンプレの答え）
- 左にコピー・右にダッシュボード風カード、の2分割に逃げる
- 順序を持たない内容に 01 / 02 / 03 と番号を振る（番号は1日の流れ・選考フローなど本当に順序があるときだけ）
- 意味のないスクロールアニメーション
- 絵文字を見出しや箇条書きの頭に使う
- 文字を画像に焼き込む（すべてHTMLテキスト）

## 言葉
- 「アットホームな職場です」「やりがいのある仕事」「成長できる環境」など、どの会社でも言える言葉
- 「革新的な〇〇を、あなたに。」のような中身のないコピー
- 根拠のない実績・数字（「満足度98%」など）、架空の社員の声を実在の人として出す
- 「家で働ける」「見てるだけでお給料」などラクさの訴求（HADOの動画CRで応募0件だった）
- 年収1000万円などの過大な年収訴求（実績の平均年収などはOK）

## 構造
- CTAがページの最後にしかない
- 給与を「経験・能力を考慮」だけでぼかす
- 応募後に何が起きるかを書かない
