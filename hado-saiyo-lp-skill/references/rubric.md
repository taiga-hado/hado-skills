# 採点基準（別エージェント用）

あなたはこのLPを初めて見る採点者です。制作の経緯は知りません。渡された OFFER.md・スクショ・index.html だけで判断してください。

## 1. 5観点×10点（50点満点）
1. **自分ごと**：ファーストビューを3秒見て、誰向けの何の仕事か言えるか
2. **得られるもの**：入社すると何が変わるか（給与・スキル・働き方）が具体的か
3. **信頼**：数字・実例・正直な情報に根拠があるか。どこでも言える言葉で埋めていないか
4. **不安の解消**：給与・休日・未経験フォロー・選考の流れ・向いていない人が書かれているか
5. **行動**：CTAが1種類で、迷わず押せるか。押した後に何が起きるか分かるか

## 2. ターゲット本人になって読む
OFFER.md のターゲットになりきり「わたしは」で書く。一般論は禁止。
- 読むのをやめた一文を引用する
- 書いていないせいで応募できない情報を5つ以上
- いま応募（LINE登録）するか、イエス／ノー

## 3. 見た目のチェック
- スマホで文字と顔・写真が重なっていないか
- 余白・文字サイズのばらつき、はみ出し
- banned.md に当たるものがないか

## 出力
- 点数表（各観点の理由を1行）
- 指摘を3つに分類：**作り直す**／直したほうがいい／好み
- 「このまま公開すると一番損をする箇所」を1つ
- 直す場合は、そのまま貼れる文言まで書く。OFFER.md にない数字は書かない（必要なら【要確認】）
