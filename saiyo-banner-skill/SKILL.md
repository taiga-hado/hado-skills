# saiyo-banner — 採用バナー・カルーセルの作り方

NSC（日本セールスセンター・2026-10-18）で確立した手順。目的は **CTR（クリック率）最優先**。説明より「止まる」こと。

## 0. 先に決めること（ヒアリング／LP・求人票から拾う）
- 誰に見せるか（1人に絞る。例：頑張ってきたのに報われていない20代）
- 事実だけの訴求素材（数字・制度・実例）。根拠のない数字は使わない
- ブランド色・ロゴ・写真（Driveの素材フォルダ）。顔出しNGの人は出さない
- リンク先＝チョクサイの流入URL（管理画面「LP・流入URL」で広告ごとに発行）

## 1. 切り口を10案出す（単体）＋カルーセル2案
田中がボツにした型（feedback_recruit_banner_angles）を避ける。**残る型は4つ**：
1. **不満の代弁**（「がんばっているのに、給料も肩書きも変わらない」）
2. **衝撃の数字**（離職率0%・未経験9割・3ヶ月で課長）
3. **対比**（ビフォーアフター・取り消し線で偏見を崩す）
4. **問いかけ**（「全部そろった営業職、ある？」）
+ UGC風（メモアプリ・スクショ風）、社員の一言（本音）も可。

**ボツになる型**：1日の流れ（タイムライン説明）、ハードル下げだけ（履歴書なし・30分でOK）、先輩紹介の順番説明。会社説明・面談の気軽さは止まらない。

カルーセルは「1枚目で引く→続きが気になる→最後にCTA」。1枚目は上の4型のどれか。各カードに見出し＋1行。

## 2. 生成（gpt-image-2・OPENAI_API_KEY）
- サイズ：単体＝**4:5（1080×1350）**（フィード最大面積）。ストーリーズ用の9:16は後回し。カルーセル＝1:1（1080×1080）
- プロンプトに入れる：日本語コピー（文字は大きく・3行以内）、配色（ブランド2色＋白）、写真かフラットか、余白、Metaの文字量目安（画面の20%程度）
- 文字化け・誤字は必ず拡大して目視。直らないときはコピーを短くする
- 1案につき2〜3枚出して1枚選ぶ。ファイル名は `A_数字_離職率0%.png` のように **記号_切り口** にする（Metaの広告名・チョクサイの流入URL名と揃える）

## 3. Driveで先方確認
- フォルダ：`<会社名>_採用広告バナー/`（01_単体／02_カルーセル／99_ボツ）
- 先方（と田中）が見てボツになったものは **99_ボツ** に移す（消さない）
- 先方に送る文：「採用広告のバナー案をDriveに入れました。ダメなものは言ってください、こちらで外します」

## 4. Meta入稿（広告マネージャ）
- 1広告＝1バナー。広告名＝ファイル名と同じ記号（A〜J、CarouselA/B）
- リンク先＝チョクサイの流入URL `https://chokusai.vercel.app/r/<code>`（広告ごとに別コード）。URLパラメータは不要（Metaが utm_content に広告IDを入れてくる。チョクサイ側で広告名に寄せる）
- カルーセルは「画像を10件まで選択」で順番どおり選ぶ。各カードに見出しとリンク
- 雇用カテゴリを申告すると年齢・性別・細かい地域が使えない（最小半径15マイル）。申告しない選択をするときは田中の判断を仰ぐ（審査・アカウント制限リスクがある）
- 公開後1〜2時間は審査「準備中」。却下が出たら文言（年齢・性別を思わせる表現）を疑う

## 5. 判断の目安（配信後）
- 1〜2日でCPCが全体平均の1.5倍以上 → 停止候補（チョクサイ管理画面「広告効果」でCPCが赤になる）
- CTRが高いのに「入力開始」が0 → 面白いだけの広告。予算を減らす
- 勝ち広告は「フックだけ変えた派生」を作って横展開（本編・デザインは固定）
