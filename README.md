# HADO skills

株式会社HADOのメンバー向け Claude Code スキルの配布用リポジトリです。
各スキルの install.sh を1行実行すると `~/.claude/skills/` に入ります。

| スキル | 導入コマンド |
|---|---|
| hado-deck（HADO標準デザインのスライド資料） | `curl -fsSL https://raw.githubusercontent.com/taiga-hado/hado-skills/main/hado-deck-skill/install.sh \| bash` |
| ai-drama（AIドラマ風広告の動画素材） | `curl -fsSL https://raw.githubusercontent.com/taiga-hado/hado-skills/main/ai-drama-skill/install.sh \| bash` |
| saiyo-lp（採用LP） | `curl -fsSL https://raw.githubusercontent.com/taiga-hado/hado-skills/main/saiyo-lp-skill/install.sh \| bash` |

※ このリポジトリは自動で同期しています。直接編集しないでください。
