# 型B：画像コラージュ型LPの作り方（2026-10-17 日本セールスセンターで確立）

HTMLだけで組むと「安っぽい・ブランドサイトっぽい」と言われたときの型。**セクションごとに gpt-image-2 で1枚絵を作り、縦に並べて1本のLPにする**。
文字入りの絵はすべて画像生成、表・タイムライン・FAQなど編集が多いところだけHTML。画像とHTMLは同じ背景色・質感でつなぐ。

トンマナ（色・質感・モチーフ・写真の扱い）は会社ごとに変える。変えるのは下の **TONE** だけで、手順とプロンプトの骨格は共通。

## 0. 成果物と置き場所
```
saiyo-lp/<slug>/
├── NOTES.md / OFFER.md / CONCEPT.md / STRUCTURE.md   ヒアリング・コンセプト・構成（型Aと同じ）
├── materials/raw|web|sheets   支給写真（gitignore）。web＝長辺1800px、sheets＝24枚ずつの一覧
├── images/*.jpg               参考として渡す写真（切り抜き元）。長辺1400px
├── images/sec/s1-fv.jpg …     生成したセクション画像（JPG q86・1024幅）
├── mocks/                     FV案（img-a.png …）
├── index.html                 本体（templates/image-lp.html から）
├── .vercelignore              materials/ mocks/ shots/ references/ *.md
└── shots/                     確認用スクショ
```

## 1. TONE を決める（会社ごとに変える唯一の場所）
DESIGN.md に次を書く。プロンプトの `{…}` にそのまま入れる。
| キー | 例（日本セールスセンター） | 決め方 |
|---|---|---|
| `{BG}` | 深緑 #0B3B33 の紙の質感 | 会社のロゴ色か、ロゴと対になる濃色。**全セクション共通**にするとつながる |
| `{PAPER}` | 生成り #F4EFE4 のマスキングテープ風ラベル／紙カード | 情報を載せる「地」。テープ／付箋／カード／フィルム／ボード など |
| `{ACCENT}` | 黄 #FFD86B（強調語・タグ・時刻バッジ） | 1色だけ |
| `{CTA}` | オレンジ #FF5A1F の丸いボタン | 背景と補色寄りで、ページ内でこの色はボタンだけ |
| `{STYLE}` | 雑誌の表紙のようなエディトリアル・コラージュ。人物は切り抜き。手書き風の吹き出し・矢印 | 他の候補：号外・タブロイド紙風／ステッカー・バッジ／映画ポスター風／方眼ノート／フィルム写真 |
| `{FONT}` | 極太ゴシック（見出し白） | 明朝にすると重く、丸ゴにすると幼くなる |
| `{MOOD}` | 明るく勢いがあるが安っぽくない、上質な紙面 | 「ゴリゴリ」「キラキラ」など避けたい語も書く |

FV案を出すときは **STYLE を変えた3案**（例：コラージュ／ステッカー／映画ポスター）。色は同じでよい。

## 2. 手順
1. **写真を読む**：ドライブから一括取得 → `materials/sheets/` に24枚ずつの一覧を作り、Readで全部見て NOTES.md に「番号→中身→使う場面」を書く。借りた場所での撮影なら「オフィス」と言わない
2. **コンセプト→コピー**：CONCEPT.md に ターゲット1人／訴求の素材（事実だけ）／コンセプト3案／表紙コピー8案。クライアントの言葉（MTG・LINE）をそのまま引用して残す
3. **FV案（画像）**：`gen_image.py` に **支給写真を --ref で渡して** 3案。HTMLモックは出さない（安っぽいと言われる）。1案だけ「動く版」が欲しいと言われたらHTML＋CSSアニメ→Playwrightで録画してmp4で渡す
4. **FV確定→仕上げ**：選ばれた案を `--ref 選ばれた案 支給写真` で作り直す。このとき「ラベルを2倍大きく」「CTA文言」など指示を全部入れる。**確定FVが以降の全セクションの参照画像になる**
5. **セクション画像**：下のプロンプト骨格で、`--ref images/sec/s1-fv.png（確定FV） 使う写真` を渡して並列生成。正方形（1024x1024）と縦長（1024x1536）を使い分ける。**上下の端は装飾なしのベタ**と必ず書く（つなぎ目のため）
6. **HTML**：`templates/image-lp.html` をコピーして、画像の `<img>` と、HTMLで持つセクション（1日の流れ・正直に・募集要項・選考・FAQ）を埋める。画像は**絶対URL**にする（チョクサイに取り込んだとき相対パスが切れる）
7. **確認**：スマホ390で全体スクショ→4分割シートで一覧。横はみ出し・画像の未読込（lazyは一度スクロールしてから撮る）・CTAの飛び先
8. **公開**：`vercel deploy --prod --yes --name <project>`（.vercelignore 必須。materials は数GB）
9. **チョクサイ**：会社を登録 → フォームの項目を「名前・電話・メール（＋年齢・都道府県）」に絞る → 職種の流れ（すぐ面談／書類）→ LPをURL取り込み（`add-lp` / 直したら `update-lp`）→ 職種を固定。広告に貼るのは `/j/<lp>` から発行した流入URL
10. 直し：画像はその1枚だけ作り直し→JPG化→再デプロイ→チョクサイで取り込み直す

## 3. プロンプトの骨格（gpt-image-2）
共通の前置き（毎回つける）：
```
1枚目の参考画像（採用LPのファーストビュー）と同じ世界観で続くセクションの画像。スマホ幅の{正方形|縦長}。
背景は{BG}、上下の端は装飾なしのベタ（上下の画像と自然につながるように）。
日本語テキストは一字一句正確に。参考画像とフォント・色・{PAPER}の質感を揃える。{MOOD}。UIモックアップとして完成度を高く。
```
### FV（縦長・写真 --ref）
```
{STYLE}。2枚目の写真の人物を切り抜いて主役に。背景は{BG}。
①左上に小さなロゴ「{会社名}」 ②{ACCENT}の太い帯に{FONT}で大きく「{職種名} 正社員募集」
③白の極太見出し「{表紙コピー}」を2行で特大（「{強調語}」は{ACCENT}） ④写真。手書き風の吹き出し「{一言}」
⑤{PAPER}の大きなラベル3段：「{訴求1}」「{訴求2}」「{訴求3}」 ⑥最下部に{CTA}「{CTA文言} ›」、下に小さく「オンライン30分・履歴書なし」
```
### 共感チェック（正方形）
見出し「ひとつでも当てはまるなら、話が合うと思います。」＋{PAPER}のラベル5枚（☑＋1行）＋{ACCENT}の手書き風で締めの1文。写真なし
### なぜ未経験でも（縦長・写真1枚 --ref）
{ACCENT}の小タグ「なぜ、…」＋見出し＋2行の文＋{PAPER}のカード2枚（教育／文化）＋写真の切り抜き＋{ACCENT}の丸囲み「実例」
### 仕事内容（縦長・写真2枚 --ref）
小タグ「仕事内容」＋見出し＋{PAPER}のカード3枚（01/02/03・番号つき）に写真を添える＋下部にラベル3枚（外回りなし など）
### 数字（正方形・写真なし）
見出し＋{PAPER}のタイル2×2に巨大数字＋小さな説明。1つだけ{CTA}色にする。下に手書き風の1文。**数字の演出は1ページ1回**
### 文化（縦長・写真1枚 --ref）
小タグ「文化」＋見出し＋3行の文＋写真の切り抜きの周りに手書き吹き出し3つ＋{PAPER}のラベルで会社の目標
### キャリアと給与（正方形・写真なし）
小タグ＋見出し＋階段状の{PAPER}カード3枚（役職｜月給）を{ACCENT}の矢印でつなぐ＋丸バッジ＋2行の補足
### 最終CTA（縦長・写真 --ref）
写真の切り抜きを上半分に大きく＋見出し（表紙と呼応）＋「今期の採用は◯名…」＋ラベル2枚＋{CTA}「{CTA文言} ›」＋「選考ではありません。話を聞くだけでOK」

## 4. HTMLで持つセクション（templates/image-lp.html）
- **1日の流れ**：横スワイプの写真カード（時刻バッジ＋写真＋見出し＋1行）。文字だけのタイムラインは「見づらい」と言われた。小さなチップの一覧も不要。最後は「退社」のカードで終える
- **先に言っておきたいこと**：{PAPER}のカード5枚（オフィス／最初の仕事／残業／男女比／向いていない人）
- **募集要項**：表（求人票どおり）
- **選考の流れ**：4ステップ、1つ目を強調
- **FAQ**：details/summary 6〜7問
- **固定CTA**：FVを過ぎたら出す。最終CTAが見えたら隠す
- **CTAアニメ**：光が走る（shine）＋脈打つ（pulse）＋矢印が動く。画像内のボタンには透明の `a.hit` を重ね、同じリズムの光の輪（ring）。`prefers-reduced-motion` で止める
- **全CTAはフォーム直行**（ページ内スクロールにしない）。`location.search` を引き継ぐ

## 5. 言われて直したこと（この型の禁止・推奨）
- HTMLで組んだFVは「安っぽい」→ 画像生成で。ギャラリーサイトの参考は「ブランドサイトっぽくて訴求が弱い」→ ダイレクトレスポンス前提で、職種名・数字・CTAを最初の1画面に
- 英字の飾り（INSIDE SALES）だけで職種を示さない。**職種名は日本語で帯に**
- 月給は押さない（押しづらい会社が多い）。離職率・成長率・休みなどに置き換える
- 「未経験OK」より「**未経験からトップセールスへ**」のように到達点を書く
- CTA文言：「面談の日程を選ぶ」より「**まずは話を気軽に聞いてみる ›**」（入口を軽く）
- FVのラベル文字は「小さい」と言われる。大きく・3段・横幅いっぱい
- 1人で腕組み・暗い映画ポスター風は「怖そう」。働いて楽しそうな写真（2〜3人が笑っている）が選ばれた
- 顔写真が無い人物（AI生成）は本番に出さない。支給写真の人物だけ
- チョクサイのフォームから「PIVOの案内（任意）」は外した（2026-10-17）
