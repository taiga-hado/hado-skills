# DESIGN.md の書き方

```markdown
# DESIGN

## 世界観（1文）
例：現場の土と鉄の質感を、白い余白で清潔に見せる

## カラートークン（4〜6色）
| 名前 | HEX | 用途 |
|---|---|---|
| ink | #1A1F24 | 本文・見出し |
| base | #F7F5F0 | 背景 |
| brand | #... | 見出しのアクセント・帯 |
| cta | #... | CTAボタンだけ |
| sub | #... | 罫線・補足 |

## 書体
- 見出し：…（ウェイト）
- 本文：…
- 数字：…（給与・時刻など。等幅 or 太字）
Google Fonts から読む。日本語は Noto Sans JP / Zen Kaku Gothic New / M PLUS 1p / Shippori Mincho などから選び、理由を1行書く。

## 文字サイズ（スマホ）
H1 / H2 / 本文 / 注記 の px と行間

## 余白
セクション間・ブロック間・左右の基準値（px）

## Signature Element（1つだけ）
このページを見た人が覚える1点。例：給与テーブルを工事の図面風に描く、現場写真の上に手書きの寸法線

## 写真のトーン
光・色温度・人物の表情・構図（寄り／引き）

## モーション
入れるなら1か所だけ。意味のある場所に

## 禁止（共通＋案件固有5つ以上）
```

書き終えたら批評する：「別の会社の採用LPでも同じDESIGN.mdにならないか」。なるなら作り直す。
