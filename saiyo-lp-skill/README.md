採用LPを同じ品質で何本でも作るための Claude Code スキル。手順と決めごとは [SKILL.md](SKILL.md)。

```bash
curl -fsSL https://raw.githubusercontent.com/taiga-hado/hado-skills/main/saiyo-lp-skill/install.sh | bash
```

- 作例：[examples/hado-kensetsu/](examples/hado-kensetsu/)（架空の建設会社・施工管理の未経験採用）
