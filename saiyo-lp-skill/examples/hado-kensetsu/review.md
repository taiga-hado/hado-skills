## 2. ターゲット本人になって読む

> わたしは25歳、家電量販店で販売をしている。土日はほぼ出勤で、このまま販売を続けても何も残らない気がしている。「手に職」をつけたいけど、建設は未経験だし、怒鳴られそうで怖い。Metaの「未経験から施工管理になりたい人へ」という動画を見てこのページを開いた。

- FVはまさに自分のことで、「22名中12名が未経験」で少し安心した。給与と休みを先に全部出してくれているのもうれしい。月27万は今より高いし、残業代が別なのも分かりやすい。
- 「入る前に知っておいてほしいこと」は、むしろ信用できた。
- **読むのをやめた一文**：選考フローの「**履歴書は面接の日に持参でOK**」。最初に「履歴書不要」と書いてあったのに、結局いるの？　ほかにも都合のいいことが書いてあるのかな、と疑い始めて、ここで手が止まった。
- FAQの「最初の半年は先輩と2人1組なので、1人で職人さんと話す場面はありません」も、その上の黒いセクションで「職人さん・お客様・管理会社と毎日話します」と書いてあったので、どっちなのか分からない。

**書いていないせいで応募できない情報**
1. 勤務時間（始業・終業）。1日の流れは8:00〜17:00に見えるけど、それが定時なのか分からない
2. 応募条件。年齢・学歴の条件は？　普通免許は要る？　現場まで車で行くのか電車なのか
3. 試用期間はあるか、その間も月27万円か
4. 社会保険・交通費（直行直帰の交通費は出るのか）
5. 住宅手当（月2万円）の条件。誰でももらえるのか
6. 現場手当はいくらか
7. 2級施工管理技士は何年働けば受けられて、取ると給料がどう変わるのか（資格手当は1級しか書いていない）
8. 1年目の年収はだいたいいくらになるのか

**いま応募（LINE登録）するか**：**イエス**。「話を聞くだけでもOK」なら、給与と休みがここまで出ている会社に聞いてみる価値はある。ただ、履歴書の食い違いのせいで「面談で条件が変わるかも」と身構えた状態で登録する。

## 4. 指摘

### 作り直す

**① OFFERにない事実の断定と、「履歴書」の矛盾を消す**
求人の条件として読まれる箇所に、OFFERにない内容が事実として書かれています。間違っていたら、面談の場で「話が違う」になります。

| 場所 | 現状 | 差し替え文言 |
|---|---|---|
| 選考フロー 4 | 履歴書は面接の日に持参でOK | `履歴書はいりません。面接は1回だけです` |
| 選考フロー 1 | 質問だけでもOK。名前と希望の連絡時間を送るだけ | `質問だけでもOK。話を聞くだけでも大丈夫です`（送る内容は【要確認】） |
| 選考フロー 2 | 私服・顔出しなしでもOK | `仕事内容と給与の説明。私服でOKです`（顔出しなしの可否は【要確認】） |
| 仕事内容 本文 | 1つの現場が1〜4ヶ月と短いので、始まりから引き渡しまでを何度も経験できます。 | `現場は小〜中規模なので、工事の始まりから引き渡しまで、全体を早く覚えられます。新築の大規模な現場より、1人が担当する範囲がはっきり見えます。`（工期の目安は【要確認】） |
| GROWTH 〜1年半 | 困ったら先輩に電話。週1回、事務所で振り返り | `困ったら先輩に電話で相談できます`（振り返りの頻度は【要確認】） |

### 直したほうがいい

**③ 比べている相手との違いを本文で言う**（「元請け比率8割」が未使用）
ターゲットは派遣会社やゼネコンとも比べています。仕事内容セクションの本文の最後に追加：
`HADO建設は、工事の8割を元請けとして受けています。派遣ではなく正社員として、自社の現場を最初から最後まで担当します。`

**④ FVのCTAの下で「押したら何が起きるか」を書く**
`<p class="cta-note">` の文言を差し替え：
`友だち追加のあと、30分のオンライン面談の日程を決めます。履歴書不要・私服OK・話を聞くだけでもOK`

**⑤ 「手に職」の中身を1行足す**（GROWTH の 2級の項目）
`2級施工管理技士は、施工管理として働き続けるための国家資格です。`（取得後の手当や昇給があれば【要確認】で追記）

**⑥ スマホの改行崩れ**
- `4.2ヶ月分）` と `夏季` を `<span style="white-space:nowrap">` で囲む
- 見出しは `h2{word-break:keep-all; overflow-wrap:anywhere}` を足すか、`<br>` で切る位置を指定する
  - `給与と休みは、<br>先に全部出します。`
  - `入る前に<br>知っておいてほしいこと`
  - `2027年までに、<br>施工管理を10名増やします。`
- 社員の声の `.who` は名前と前職の間を `<br>` にする

**⑦ 18ヶ月の寸法線は1回だけにする**
FVに残すなら、GROWTH の `.dim` は削除する（本文に同じ内容がある）。

**⑧ FV写真の縦線**
縦線とラベルの位置を、職人さんの頭にかからない左側の窓まわりへ移すか、`top` を下げて頭の上を通らないようにする。

### 好み

- セクションラベルが英語の小見出し（WORK / SALARY など）。ターゲット層には日本語（仕事内容／給与・休み）のほうが目に入りやすいかもしれない
- CTAの文言がセクションごとに4通りある。同じリンク先なので問題ないが、「LINEで仕事内容を聞いてみる」に1本化すると覚えやすい
- FVの「1人で現場を持つまで18ヶ月」は安心材料にもなるが、「1年半も一人前になれない」と読む人もいる。FVを「最初の6ヶ月は先輩と2人1組」にする案もある
- 最後の見出し「2027年までに、施工管理を10名増やします。」は会社側の都合に見える。`未経験の方を前提に、施工管理を10名採用します。` のほうがターゲットに向いている

## 5. このまま公開すると一番損をする箇所

**選考フロー 4「履歴書は面接の日に持参でOK」**

FVと各CTAの下で「履歴書不要」と言い続けたあと、最後のCTAの直前でそれを覆しています。ちょうど応募を決める場所で「このページの約束は本当か？」と疑わせてしまい、それまでに積み上げた正直さ（給与を全部出す・きつい点を先に言う）の効果が消えます。

差し替え：
```html
<li><span class="n num">4</span><div><b>面接（1回）</b><br><span>履歴書はいりません。面接は1回だけです</span></div></li>
```
