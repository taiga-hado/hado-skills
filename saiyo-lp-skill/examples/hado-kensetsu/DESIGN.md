# DESIGN

## 世界観
現場の図面と、白い作業着の清潔さ。「きつそう」を「段取りの仕事」に見せる

## カラートークン
| 名前 | HEX | 用途 |
|---|---|---|
| ink | #1C2024 | 本文・見出し |
| paper | #F3F0E8 | 背景（図面用紙のような生成り） |
| blueprint | #1F4E79 | 見出しの帯・図面の線・数字 |
| caution | #F2B705 | アクセント（安全帯の黄色）。1画面に1か所まで |
| line | #06C755 | CTAボタンだけ（LINEの緑） |
| rule | #C9C3B6 | 罫線・方眼 |

## 書体
- 見出し：Zen Kaku Gothic New 900（太く短く。現場の看板の強さ）
- 本文：Noto Sans JP 400/700
- 数字：Barlow Condensed 700（給与・時刻・寸法。図面の数字の雰囲気）

## 文字サイズ（スマホ）
H1 34px/1.25 ・H2 26px/1.35 ・本文 16px/1.85 ・注記 12px

## 余白
セクション間 88px ・ブロック間 28px ・左右 20px

## Signature Element
**寸法線**。写真・給与・期間の横に図面の寸法線（両端に矢印、中央に数字）を引き、「入社から1人で現場を持つまで 18ヶ月」のように仕事の段取りを"測って"見せる。他の装飾はしない

## 写真のトーン
晴れた日の自然光・やや高めの色温度。ヘルメットと白い作業着、20代の社員が職人さんと話している／図面を見ている。引き1：寄り1。笑顔を作りすぎない

## モーション
寸法線がスクロールで端から伸びる1か所だけ

## 禁止
- 共通：banned.md
- オレンジ×黒の「工事現場ど真ん中」配色（どの建設会社も同じになる）
- クレーン・高層ビル・夕焼けシルエットの写真（新築の大規模現場のイメージで、改修の実態と違う）
- 「未経験でも安心！」の吹き出しイラスト
- ヘルメットのアイコンを見出しに並べる
- 「地図に残る仕事」（建設採用で使い古された言葉）
